JG STUDIO APPS — SEO GÜNCELLEMESİ
Tarih: 9 Ekim 2026

Bu klasörün içindeki dosya ve klasörleri GitHub Pages deponuzun kök dizinine yükleyin.
Mevcut dosyalar sorulduğunda değiştirin.

APP-ADS.TXT UYARISI:
- Mevcut app-ads.txt dosyanızı silmeyin, değiştirmeyin veya yeniden yüklemeyin.
- app-ads.txt bu teslim paketine özellikle dahil edilmemiştir.
- Böylece yayındaki doğrulanmış reklam kaydı olduğu gibi kalır.

Önemli:
- CNAME dosyanız depoda zaten varsa silmeyin.
- GitHub Pages üzerindeki HSTS, X-Frame-Options ve CSP gibi HTTP header'ları HTML dosyasından ayarlanamaz. Bunlar CDN/hosting katmanı gerektirir.
- Yayından sonra https://www.jgstudioapps.com/sitemap.xml adresini Google Search Console'a gönderin.
- GA4 G-536YWXEMQ3 yalnızca ziyaretçi analiz izni verdikten sonra yüklenir.

Paket içeriği:
- index.html: SEO ve içerik iyileştirmeli ana sayfa
- privacy.html: güncellenmiş canonical ve sosyal meta veriler
- 404.html: özel hata sayfası
- robots.txt ve sitemap.xml: jgstudioapps.com alan adına göre düzeltildi
- site.webmanifest, favicon.ico, apple-touch-icon.png ve assets/icon-512.png
- assets/social-card.jpg: sosyal paylaşım görseli
- app-ads.txt: pakete dahil değildir; GitHub deposundaki mevcut dosya korunmalıdır
